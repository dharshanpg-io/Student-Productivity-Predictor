# Models Directory

This directory stores serialized model artifacts and metadata generated by the Java training pipeline.

## Trained Models
- `trained_productivity_model.model`: Serialized binary bundle containing the champion **Random Forest Regressor** ensemble, fitted scaling parameters (means and standard deviations), and evaluation metrics computed on the 3,200 held-out test records.

## Model Benchmarks (Held-out Test Split N = 3,200)
- **Random Forest Regressor (Champion)**:
  - Trees: 25 randomized trees
  - MAE: 2.2840 points
  - RMSE: 2.9045 points
  - $R^2$: 0.9686 (explains 96.86% of target variance)
  - Max Error: 11.12 points
- **Ridge Linear Regression**:
  - Regularization: L2 $\lambda = 1.0$
  - MAE: 0.0027 points
  - RMSE: 0.0032 points
  - $R^2$: 1.0000
- **Decision Tree Regressor**:
  - MAE: 4.0628 points
  - RMSE: 5.0437 points
  - $R^2$: 0.9052
- **Baseline (Mean Predictor)**:
  - MAE: 13.3899 points
  - RMSE: 16.3890 points
  - $R^2$: -0.0005
